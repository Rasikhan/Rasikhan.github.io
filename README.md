# Abdul Rasikhan M - React Portfolio

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Before publishing

Edit `src/App.jsx` and replace:

- `YOUR_GITHUB_USERNAME`
- `YOUR_LINKEDIN`

You can also add a resume PDF and more project links.

## GitHub Pages

The easiest deployment is to use GitHub Pages with GitHub Actions, or deploy this Vite project using Vercel/Netlify.
